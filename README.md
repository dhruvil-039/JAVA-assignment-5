# Shape Calculator (Java)

This is a Java-based menu-driven console application that calculates Area, Perimeter, and Volume for various shapes using Object-Oriented Programming concepts like Abstraction and Interfaces.

## Classes Included
- **Shape.java**: Abstract class with common methods.
- **Volume.java**: Interface for volume calculations.
- **Circle, Rectangle, Square, Sphere, Cylinder, EquilateralPyramid**: Shape-specific classes.
- **ShapeMain.java**: Main driver program.

## How to Compile and Run

```
javac *.java
java ShapeMain
```
